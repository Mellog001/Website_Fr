# File Storage

Provider:
AWS S3 or Cloudflare R2

Pattern:

1 Request upload URL
2 Upload directly
3 Confirm upload

Supported Files:

- Qualification Documents
- Assessment Papers
- Student Submissions
- Course Materials
- Avatars

Requirements:

- Presigned URLs
- MIME validation
- Size validation
- Virus scanning ready
- Cleanup jobs

Generate:

storage service
upload handlers
download handlers
